# Performance Analysis of ISAC Slicing with Sensing-Assisted Communication and Communication-Assisted Sensing

This is the public repository for all the code used in our paper's evaluations.
Our ISAC Slicing Simulator is purely written in Python with vectorized operations using NumPy.
The scripts that execute our evaluated simulations, as well as the plots we included in the paper, are contained in Jupyter Notebook files.
Each Notebook generates 1 of the figures included in the paper.
You can replicate our results using a local Jupyter Notebook server.

A preprint of our paper is available on [ArXiv](https://arxiv.org/abs/2610.03879).

The slides presented in the IEEE ISAC 2026 Conference are available [here](https://scholar.google.com.br/citations?user=NEuyEkUAAAAJ).

## Dependencies

All simulations were executed using a Python 3.10 kernel.

Make Sure you have the following packages installed in the Python kernel you use to run the Jupyter Notebooks:
- matplotlib
- numpy
- scipy
